# My E-Commerce Store

Welcome to **My E-Commerce Store**! This project is a simple, responsive e-commerce website showcasing eco-friendly bamboo eyewear. The site allows users to view products, 
make purchases, and learn about the store's privacy policy.

---

## Features

### 1. **Home Page**
- Showcases the store's branding and available product categories.
- Simple navigation menu linking to other pages.

### 2. **Buy Now Page**
- Users can fill out a form with details like name, email, address, and payment information to complete their purchase.
- Form submission redirects users to the **Order Confirmation** page.

### 3. **Order Confirmation Page**
- Displays a thank-you message for successful purchases.
- Includes a button to return to the home page and continue shopping.

### 4. **Privacy Policy Page**
- Outlines how user data is collected, used, and protected.
- Includes contact information for user inquiries.

---

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and making the site visually appealing.
